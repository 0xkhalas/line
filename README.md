# line
A simple programming language implemented in Self using Nest compiler.

## Features

- Custom syntax and parser
- LLVM

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/0xkhalas/line.git
    cd line
    ```

## Usage

You can write your `.line` files and run them using the CLI provided in this project.
